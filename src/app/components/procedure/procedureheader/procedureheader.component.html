Guidelines for Procedure Approvals

For a “minor” procedure (legacy work order), approvers during system I&T are typically:

  • I&T Lead Engineer
  • System Assurance Manager
  • System Safety Engineer (only if this is a hazardous procedure)
  • Cognizant Engineer (such as a subsystem lead, if necessary)

For a “major” procedure (legacy PLM procedure), approvers during system I&T should follow the project signature authority memo for I&T procedures.
